# Release Workspace Demo

An interactive product demo for release verification and workflow-boundary handling.

## Included surfaces

- **Release QA:** run a focused release verification pass and inspect the resulting go/hold decision.
- **Workflow integration:** route valid, malformed, and duplicate events to distinct outcomes with a visible event history.

## Run locally

Open `index.html` in a modern browser. The site has no build step, dependencies, backend, or external network calls.

## Scope

This is an independent product demo built with HTML, CSS, and browser JavaScript. It does not represent a client engagement or production deployment.
